RADAR VINH - SOURCE CODE

Main source file: index.html

This project was supplied as a single HTML file. Its CSS and JavaScript are embedded in index.html, and the visible embedded image/font assets are included as data URLs.

To preview locally: open index.html in a modern web browser.

For static hosting: upload the folder containing index.html, or upload the index.html file if the hosting provider accepts a single-file site.

Note: the HTML references Google Fonts domains for font loading; an internet connection may be needed for any externally hosted font resources. The page also contains code that may retrieve live data/services; those external services are not bundled into this file.
